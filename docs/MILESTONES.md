# Semester Milestones

These are the planned Senior Design phases. Exact presentation/due dates can be copied into GitHub Milestones from the course calendar.

| Milestone | Goal | Evidence |
|---|---|---|
| Phase 1 — Scope and parser prototype | Define the research question and show syntax-aware detection on small Nix examples. | README, parser prototype, fixtures, initial tests, design notes. |
| Phase 2 — Safe rewrite engine | Produce source edits only for a documented safe subset. | Golden before/after fixtures and refusal cases. |
| Phase 3 — Nixpkgs repository integration | Scan tracked package files and support dry-run/apply with Git safety checks. | End-to-end demo on a disposable checkout. |
| Phase 4 — Validation and measurement | Measure correctness, idempotence, parse validity, and supported-vs-manual coverage. | Test suite, result tables, tagged experiment commits. |
| Phase 5 — Final evaluation and paper | Evaluate representative real cases and document limits. | Results, final demo, reproducible write-up. |
